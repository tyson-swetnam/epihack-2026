# Glossary

| Term | What it means here |
|---|---|
| **AZ One Health Sentinel** | The whole stack (this archive). |
| **DuckLake** | An open-lakehouse format. Data in Parquet/object storage, catalog in Postgres, queries in DuckDB. |
| **FastMCP** | Python library for building MCP servers. Used by all 11 servers. |
| **HeatRisk** | NWS forecast product — 5-day, 0-4 risk index. |
| **ICD-10 / SNOMED / LOINC** | Clinical terminologies seeded in `schema/deep/standards.sql`. |
| **kg.node / kg.edge / kg.property** | The property-graph triple of tables. |
| **MCP** | Model Context Protocol — the JSON-RPC standard for LLM tool servers. |
| **One Health** | Surveillance framing that treats human, animal, and environmental health as one system. |
| **VBD** | Vector-Borne Disease (one of the two focus groups). |
| **VectorSurv** | National mosquito/tick surveillance API (UC Davis). |
| **WHISPers** | USGS Wildlife Health Information Sharing Partnership. |
| **X-Client-Channel** | HTTP header routing `mobile` writes to MongoDB and `web` writes to DuckLake. |
| **ZCTA** | ZIP Code Tabulation Area — the Census Bureau's polygon equivalent of a ZIP code. |
