Knowledge graph

The structured content above is mirrored in SQL seeds for a property graph encoded in DuckLake (with Postgres as the catalog) and queried via DuckDB:

  • schema/knowledge_graph.sql — core nodes, edges, properties from Figures 1–4.
  • schema/system_designs.sql — worksheet template, focus areas, completed designs.
  • schema/world_cafe.sql — World Café Q4 engagement examples and tactics.
  • schema/wildlife_vectors.sql — wildlife / vector-borne focus group, four questions, and 30+ anchor resources across state, county, tribal, federal, academic, and citizen-science jurisdictions.
  • schema/heat.sql — Heat focus group, four questions, vulnerable populations, and 30+ heat-specific resources (ADHS BRACE, MAG HRN, Phoenix OHRM, NWS HeatRisk, UA Heat Resilience Initiative, CLIMAS, 211 Arizona).

See the README for bootstrap commands and example queries.
