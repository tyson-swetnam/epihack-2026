About this workspace

The dashboard is read-only. The "Verify outbreak" write action from Scenario D step 6 is described in each agency view as a future-work box; in the Phase 3 pilot it ships as a separate, audited write workflow that goes through the Knowledge Update Agent.

Every pin and every row carries a kg_node_id that round-trips to the geospatial map, the pathogen graph, and the underlying SQL nodes seeded by schema/.

Future work (not in this prototype): agency SSO (ADHS Entra ID, MCDPH AD, AZGFD employee portal, Coconino HHS); per-agency DUAs; the "Verify outbreak" write workflow that writes a Verify milestone event back to the knowledge graph via knowledge-graph-mcp (a write-tooling MCP that ships separately from the read-only server bundled here); cluster-detection threshold calibration against historical AZ data (1993 Four Corners, 2021 Maricopa WNV, 2023/2024 heat seasons, 2025 Coconino plague).
