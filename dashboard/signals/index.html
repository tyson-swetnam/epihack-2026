EpiHack AZ 2026 · agency dashboard

Statewide signal monitor live aggregate

This view reads a privacy-safe ZCTA-week aggregation exported from the live DuckLake knowledge graph — the same store the intake write-path persists every report into. It is the analyst-facing read of the Cluster Detection Agent: it highlights where a category of report is arriving above its expected statewide share.

What this is — and is not. Every signal below is an above-baseline count of what people reported (e.g. febrile/rash reports, gastrointestinal/food-safety reports, animal die-off/bite reports). It is never a diagnosis: no disease, pathogen, or cause is inferred or named here, by design. Confirming a cause is a downstream, human, agency act (Scenario D), not something this surveillance feed asserts. Aggregations are ZCTA-week; no individual observation, precise location, or free-text note is exposed.
