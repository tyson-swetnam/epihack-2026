Deep schema seeds

Twelve domain-specific seeds produced by parallel deep-research sub-agents. Each file is idempotent (every INSERT uses ON CONFLICT DO NOTHING) and reserves a numeric block of edge_id values to avoid collisions with the others.

File index

File What it seeds Edge IDs
pathogens.sql Pathogens with vectors, reservoirs, AZ presence, ICD-10 codes, and surveilling agencies. Drives the Cytoscape pathogen graph. 10000–10999
tribes.sql All 22 federally recognized AZ tribes: enrollment, land base, epidemiology contacts, ITCA-TEC affiliation, sovereignty annotations. 11000–11999
counties.sql All 15 Arizona counties (FIPS, seat, area, population, vector-control program) plus agency-to-county edges. 12000–12999
datasets_apis.sql Upstream datasets and APIs (NEON, WHISPers, NWS, GBIF, iNat, VectorSurv, AZGFD, ArcGIS Feature Services, …) modeled as resource and api nodes. 13000–13999
outbreaks.sql Historical AZ outbreaks (hantavirus, plague, WNV, …) with the Figure 3 timeliness-milestone dates (Detect → Notify → Verify → Lab → Respond). 14000–14999
standards.sql Interop standards: FHIR, OMOP CDM, ICD-10, SNOMED CT, LOINC, Darwin Core, GeoSPARQL. 15000–15999
mcp_servers.sql MCP servers and their exposed tools as graph nodes (mcp_server, mcp_tool, api), wired up with wraps / exposedBy / informs edges. 16000–16999
application.sql Application runtime types: observation node type, heat / VBD symptom and exposure enumerations, consent profiles, wearable metrics, triage-class enum (tc.*). Depends on knowledge_graph.sql. 20000–20999
followups.sql Idempotent patch file: small gaps the Phase 0 sub-agents flagged (missing SNOMED codes, county aliases, …). Run after every other seed. 30000–30199
audit.sql Agent-runtime audit log (one row per agent invocation) plus a per-observation timeliness pivot view that anchors the Figure 3 milestones. Depends on application.sql. 40000–40999
cluster_followups.sql Closes the eight historical-outbreak gaps the cluster-detection calibration sub-agent itemised in plan/CLUSTER-CALIBRATION. Adds single_case_alertable flags read by the Tier-A detector at runtime. 50000–50999
outbreaks_near_me.sql Boston Children's / HealthMap Outbreaks Near Me as a resource_org + dataset, with edges to vector-borne / zoonotic focus areas and the Figure 3 Detect milestone. 60000–60999
