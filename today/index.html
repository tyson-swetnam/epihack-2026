    How this works

    Every number above comes from an MCP server in the mcp/ tree. The page aggregates and anonymises — no personal data ever appears on this page no PII. The agency-facing dashboard (Phase 3) sees the line-data; this page sees only counts and rates.

    Read the architecture in the plan, the framework figures in figures/, or the per-source docs in nws-heatrisk-mcp, mag-hrn-mcp, vectorsurv-mcp, whispers-mcp, inaturalist-mcp, adhs-mcp, 211-az-mcp, knowledge-graph-mcp.

    Inspired by — and a complement to — Outbreaks Near Me (Boston Children's Hospital / HealthMap; successor to Flu Near You). OBNM covers the human symptom-self-report side; this page focuses on the wildlife / vector / heat signals OBNM doesn't cover.
