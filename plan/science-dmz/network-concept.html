UNM CARC · Science DMZ planning · concept v1 · July 2026

BigByte × CARC × HSC — proposed network topology

Two data planes over shared metro fiber: an open Science DMZ (Internet2 → GigaPoP → BigByte, no inline firewall) for the 10 PiB/month OSN + CyVerse workload, and a parallel Medical Science DMZ path (encrypted, firewalled, BAA-covered) for HSC PHI moving between the HSC, the CARC secure enclave, and the HSC cage at BigByte.

Science / R&E — line-rate, ACLs + offline IDS, no stateful firewall PHI / HIPAA — MACsec/IPsec encrypted, firewalled both ends, BAA Enterprise / commodity — through campus firewall Passive tap / OOB mgmt

Open science path (blue)

  • Internet2 → GigaPoP → BigByte Science DMZ at 2×100G — the 10 PiB/month peak workload never touches the campus enterprise network or any per-GB billing.
  • No inline stateful firewall. Security is line-rate router ACLs plus Zeek IDS on an optical tap — the defining Science-DMZ pattern; a firewall in this path caps throughput far below 100G.
  • A metro-fiber Science-DMZ VRF extends the DMZ to CARC so HPC jobs read/write OSN S3 at line rate, bypassing the enterprise firewall by design. CARC's current ~10G campus DMZ segment must be upgraded to 100G for this to hold.
  • CyVerse K8s cluster sits beside the OSN pod — its pods hit S3 over the colo's local fabric, so CyVerse's ephemeral workloads never burn WAN bandwidth.
  • perfSONAR at both ends (GigaPoP + BigByte) provides continuous loss/throughput evidence for the whole path.

PHI path — Medical Science DMZ (red)

  • PHI never enters the open DMZ. It rides a separate VRF on the same LoboNet fiber, MACsec/IPsec-encrypted end to end, with stateful firewalls at every boundary.
  • Three PHI zones: HSC systems, the HSC-funded secure enclave inside CARC (encrypted scratch, no route to the open DMZ), and the HSC cage at BigByte (under BigByte's existing HIPAA/HITECH posture + a BAA).
  • De-identified outputs cross to the open science side only through the HSC staging/de-id pipeline — one controlled, audited crossing point.
  • Follows the ESnet/NIH "Medical Science DMZ" design pattern: high-throughput and HIPAA-aligned, by encrypting and segmenting rather than bottlenecking through the enterprise firewall.

Enterprise path & operations (grey)

  • Business traffic keeps its existing route: GigaPoP → campus border → enterprise firewall. Nothing about the DMZ changes campus security posture.
  • Out-of-band management reaches DMZ gear via a small, separate firewalled path — engineers never depend on the 100G data plane to fix the 100G data plane.
  • Staffing map: HPC Engineer owns the DMZ/data plane; DevOps-Security (split with UNM IT) owns ACLs, Zeek, and the enterprise boundary; IT Manager owns BigByte/OSN/I2 contracts and the BAA; CyVerse RSEs run their own K8s cluster.
